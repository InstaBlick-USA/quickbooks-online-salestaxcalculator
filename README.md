# Sales Tax Calculator API for QuickBooks Online

A QuickBooks Online integration for requesting tax results for estimates and invoices.

**Status: scaffold only. This integration is not published or ready to install.**

## Planned scope

- Connect a QuickBooks Online company and a Sales Tax Calculator API account.
- Map transaction lines, customer location, currency, and tax treatment to an API request.
- Return the API outcome and amounts for the transaction workflow.
